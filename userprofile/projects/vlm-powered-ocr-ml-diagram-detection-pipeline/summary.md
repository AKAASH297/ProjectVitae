A pipeline integrating Vision-Language Models (VLMs) with OCR and machine learning for detection and analysis of diagrams. The repository contains Python scripts for image pre-processing, OCR extraction, VLM inference (e.g., Salesforce BLIP, HuggingFace Transformers), and ML-based diagram element classification. Includes modules for text detection, optical character recognition, object detection (using models like EfficientDet), and a unified pipeline to process engineering or technical diagrams. Features include configurable pipelines, result visualization, and a data loader for custom datasets.
